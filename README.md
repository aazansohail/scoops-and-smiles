# Scoops & Smiles

Ice cream shop management app built with Python and SQLite.

## Files

- scoops_smiles.py - entry point
- menu.py - menu / UI logic
- logic.py - business logic
- database.py - database layer
- validation.py - input validation
- reports.py - reporting
- seed_demo_data.py - seeds demo data
- scoops_smiles.db - SQLite database

## Run

```
python scoops_smiles.py
```
